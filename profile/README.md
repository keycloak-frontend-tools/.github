### Keycloak Frontend Tools

Open source projects that bring modern frontend developer experience to Keycloak — typed roles, native UI components, login themes without Freemarker wrestling, and secure BFF patterns.

**Website:** [keycloak-frontend-tools.github.io](https://keycloak-frontend-tools.github.io/keycloak-frontend-tools/)

---

#### Projects

| Project | What it does |
| --- | --- |
| [**keycloak-headless**](https://github.com/keycloak-frontend-tools/keycloak-headless) | Lit web components + React / Vue / Svelte / Solid helpers for SPAs |
| [**keycloak-react**](https://github.com/keycloak-frontend-tools/keycloak-react) | Clerk-style React components for Next.js with SSR (Auth.js) |
| [**login-ui-base**](https://github.com/keycloak-frontend-tools/login-ui-base) | Modern Keycloak login themes — client-side UI or Quarkus Qute |
| [**Backend-for-Frontend**](https://github.com/keycloak-frontend-tools/Backend-for-Frontend) | Keycloak extension: BFF session cookies, tokens stay server-side |
| [**theme-preview**](https://github.com/keycloak-frontend-tools/theme-preview) | Preview custom login themes while developing |
| [**login-ui-alpine**](https://github.com/keycloak-frontend-tools/login-ui-alpine) | Alpine.js based Keycloak login theme |

Keep Keycloak’s OIDC architecture. Get the DX frontend developers expect.
